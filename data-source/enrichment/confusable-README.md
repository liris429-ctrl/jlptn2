# confusable.json 欄位說明

N2 文法辨析誘答資料。以 grammar `id` 為 key，於 `data:build` 加工層 merge 進題庫，**不改上游 CSV**。

## 覆蓋範圍（重要）

- **實際配置：72 條**（白名單 140 條中，涵蓋所有密集易混群 + 部分長尾）。
- 未配置的約 60 餘條，多為近義對稀少的獨立文法（さえ・など・ものか・向けだ・最中だ 等），本就無強誘答，**應走出題引擎的同課次/功能群 fallback**，不硬配。
- 白名單檔（whitelist.json）為手抄對照用，**實際請以你 build 輸出的 grammar.json 動態生成**（本檔僅列到 138，可能有謄漏）。

## 欄位

| 欄位 | 層級 | 給誰用 | 說明 |
|---|---|---|---|
| `reason` | confusable 項 | **學習者**（答錯後的解析） | 兩文法語意差異的說明文字，顯示用 |
| `id` | confusable 項 | 引擎 | 誘答文法的 id，須為白名單內真實 id |
| `distractorTrap` | confusable 項（選填） | **引擎/命題** | 出題時可用的句法陷阱線索，**不顯示給學習者** |
| `pairForm` | confusable 項（選填） | 引擎 | 此誘答放進題幹時應優先取用的**變體形態**（如 わけがない→ないわけがない） |
| `pairNote` | confusable 項（選填） | 命題備註 | 說明 pairForm 為何誘答力更強 |
| `_filtered` | confusable 項 | 引擎 | `true` 表此誘答 id 不在白名單、**引擎應略過**（待資料源補齊後生效） |
| `_filterReason` | confusable 項 | 人 | 說明為何被過濾 |
| `usageSplit` | 條目層（選填） | 命題 | 標記一個文法的**多個義項**（如 に対して 有對象義/對比義），供未來擴充 |
| `_futureSplit` | 條目層（選填） | 人 | 標記「上游合併成一條、但內部有可拆線索」的 id（如 ばかりだ-一方だ），**現狀不拆**，附未來拆分依據 |
| `_` 前綴欄位 | 任意 | — | 引擎讀取時應**忽略所有 `_` 開頭欄位** |

## distractorTrap 七類線索（按客觀強度排序）

引擎/命題取用時，**優先用強線索**（能用封閉詞表就不用形態、能用形態就不用語感）：

1. **封閉詞表/固定搭配**（最強）— 限り 前接極限詞、をめぐって 後接議論対立、までもない 搭言う/調べる。查有限清單，機械可判。
2. **純形態接續** — ようとしている 接意向形、たくて vs たい、た形 vs 辭書形。看詞尾，零爭議。
3. **句法角色/後綴** — に対して 對象 vs 主題、限り 的 は/では 有無。需輕度剖析。
4. **前接名詞類型** — に基づいて 接規範型、にこたえて 接期待型。
5. **副詞共現** — としても 配いくら/どんなに、ことか 配なんと。
6. **句型搭配框架** — というものではない 嵌 ～ばいい。可反用作題幹生成模板。
7. **後項性質/主詞限制**（偏語感）— 意志 vs 意外、情緒極性、人稱限制、時態。**多數清楚但有灰帶**。

## 自動判分警告

- 第 7 類（語感類）trap 為「**命題傾向**」非無例外鐵則。自動判分**僅採第 1–3 類形態層**線索；勿以語感類 trap 判錯邊緣正解。
- 封閉詞表雖強，「封閉」是相對的（涵蓋 95%+ 情境，非數學全集），當「強優先線索」安全，勿當「詞表外一律判錯」的封閉規則。

## 出題引擎必備的兩層邏輯（資料層不含，引擎需自建）

1. **白名單過濾**：略過所有 `_filtered:true` 及任何 id 不在當前 deck 白名單的誘答。
2. **數量不足補位**：過濾後有效誘答 < 3（四選一需 3 個誘答）時，從**同 lesson 課次**或**同功能群**補足選項。本資料有 13 條有效誘答僅 1 個，**必依賴此補位邏輯**才出得成完整題。

## id 去重警告

多組 id 表面字串高度重疊，**比對/去重只能認完整 id 字串，禁用模糊包含匹配**：
- `つつ` / `つつも` / `つつある`（三個獨立 id、意思全異）
- `限り` / `限りでは` / `限りは`（三個獨立 id）
- 同一表面形態（如「にしても」）可能分屬 `にしたら-...-にしても` 與 `としても-にしても-...` 兩個 id — 去重看 id、不看表面字串。
