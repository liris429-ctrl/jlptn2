# 資料源缺口清單

配置誘答過程中反覆撞到的「N2 高頻、但上游 deck 未收」的文法。這些**無法當誘答**（會被白名單過濾），也可能是題庫覆蓋的盲點。

## 缺口文法（依補入優先度）

| 文法 | 類型 | 為何缺、影響 | 補入優先度 |
|---|---|---|---|
| **までもない** | 獨立高頻考點 | 有獨特考點（言うまでもない）與陷阱（言うことはない 語意岔開），缺了很可惜 | **高** |
| **とは限らない** | 高頻 | 是 というものではない 的天然誘答，缺了該辨析題出不成 | **高** |
| **反面 / 対比義の一方で** | 高頻 | に対して 對比用法的天然誘答；「一方」現有 id 是加劇義、對不上 | **高** |
| **において** | 泛用 | 多條依據/場域類文法的自然誘答，反覆想用卻不在庫 | 中 |
| **について** | 泛用 | をめぐって 的自然誘答（現只有 に関して） | 中 |
| **たびに** | 泛用 | につけて 的自然誘答 | 中 |
| **はもちろん** | 口語變體 | はもとより 的口語對照；多教材當附帶不單列，可低優先 | 低 |
| **ないと** | 基礎條件 | ないことには 的口語對照；N4 級、可不補 | 低 |
| **のに** | 基礎逆接 | にもかかわらず 的口語對照；N4 級、可不補 | 低 |

## 觀察：上游 deck 的取捨特性

這份 deck 系統性偏收「較特殊/進階」的 N2 文法，排除大量「N3 延續、N2 仍高頻」的基礎項。
- 對 **SRS 複習**無影響（本就練清單內的）。
- 對 **出題**有實質影響：這些基礎高頻文法無法當誘答，而它們恰是最自然的干擾項。

## 建議下一步

建一個自有補充檔 `grammar-supplement.json`，與 confusable 同樣掛在 `data:build` 加工層、**不碰上游**，把上表「高」優先的幾條補成合格 id（含 pattern / meaning / 接續 / 至少一例句）。效益：
1. 這些文法可當誘答 → 修好上述辨析題。
2. 必要時可自己出題 → 補題庫覆蓋。

比繼續堆 confusable 槓桿更高，因為同時解「誘答不足」與「題庫覆蓋不全」。
